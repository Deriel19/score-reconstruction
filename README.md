# Score Poderoso - Reconstrução

Abra `index.html` diretamente no navegador para visualizar a página.

Estrutura principal:
- `index.html` - página completa
- `styles.css` - layout desktop, mobile e ultrawide
- `script.js` - contador visual da oferta
- `public/reference-assets/` - assets reconstruídos/recortados das referências fornecidas

A página foi calibrada com foco na referência desktop de 1341 px e contém comportamento responsivo para telas menores e centralização com margens pretas em monitores ultrawide.
